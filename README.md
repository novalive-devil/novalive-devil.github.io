# NOVALIVE — Gaming, Editing & Tools Portal

A responsive static website built with HTML, CSS and vanilla JavaScript.

## Features
- Responsive desktop/mobile navigation
- Search and category filters for resource cards
- Included gaming, editing and creator checklist downloads
- Text case transformer
- Random colour palette generator with click-to-copy HEX values
- Hashtag helper
- Social hub links (Instagram and YouTube prefilled; other links can be added later)
- No build tools, paid services or external JavaScript libraries required

## Publish on GitHub Pages
1. Upload the contents of this folder into the root of `novalive-devil.github.io`.
2. Open repository **Settings → Pages**.
3. Set source to **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.
4. Wait for deployment and open `https://novalive-devil.github.io`.

See `START-HERE-HINDI.txt` for detailed Hindi instructions and notes about placeholders.

## Important
This is a static site, not a secure admin system. Visitors can see the source code and public files. Do not upload secrets, personal data, cracked software or files you do not have permission to share. The contact email is a placeholder until changed.
