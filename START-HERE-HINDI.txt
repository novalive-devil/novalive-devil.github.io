NOVALIVE V1.1 — NEON PORTAL
===========================

Is version mein design ko dark black + cyan + blue/purple neon style mein update kiya gaya hai, reference screenshots se inspired.

WEBSITE FILES
- index.html: website structure
- style.css: responsive design/theme
- script.js: filters, search aur browser tools
- *.txt: sample downloadable resources
- favicon.svg: browser tab icon
- robots.txt: crawler instruction

GITHUB PAGES PAR UPDATE KARNE KA TARIKA
1. ZIP ko extract karo.
2. Extracted folder ke andar ki files select karo — index.html, style.css, script.js aur saari .txt files.
3. GitHub repository kholo: https://github.com/novalive-devil/novalive-devil.github.io
4. Add file > Upload files par click karo.
5. ZIP ke andar wali files ko repository ke main/root level par drag-and-drop karo. Index.html kisi extra folder ke andar na rahe.
6. Neeche Commit changes par click karo.
7. Settings > Pages mein main branch aur /(root) selected rehne do. Kuch minute baad https://novalive-devil.github.io/ refresh karo; zaroorat pade to Ctrl+F5 dabao.

CUSTOM LINKS
Instagram aur YouTube links current HTML mein configured hain. Discord/Telegram link tabhi kaam karega jab apna actual invite/channel URL add karoge. Contact email abhi placeholder hai.

IMPORTANT
- GitHub Pages static hosting hai. Is website mein abhi login/admin dashboard, cloud file uploads ya database nahi hai.
- Sample downloads basic text/checklist files hain. Apne original tools, presets ya assets ke links baad mein add kar sakte ho.
- Public GitHub repository mein uploaded files sab dekh sakte hain. Passwords, API keys ya private details upload mat karna.
- Apni hi ya share karne ki permission wali files upload karo; pirated/cracked software nahi.
