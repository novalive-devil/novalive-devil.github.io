NOVALIVE V1.3 — HINDI SETUP

Is version mein landing page aur main portal ko screen recording ke dark neon cyan/purple style ke kareeb banaya gaya hai.

GITHUB PAR UPDATE KARNE KE STEPS:
1. ZIP download karke right-click > Extract All karo.
2. https://github.com/novalive-devil/novalive-devil.github.io kholo.
3. Add file > Upload files par click karo.
4. Extracted folder ke andar ki saari files select karo. ZIP file ko seedha upload nahi karna.
5. Files repository ke root par upload honi chahiye; kisi extra folder ke andar nahi.
6. Same naam wali files ko replace hone do. index.html, portal.html, script.js, style.css, landing.css aur favicon.svg zaroor update hon.
7. Neeche Commit changes par click karo.
8. 1–3 minute baad https://novalive-devil.github.io/ ko Ctrl+F5 se refresh karo.

FLOW:
- Landing page par social links aur JOIN NOW / JOIN PORTAL button rahega.
- JOIN NOW par click karne se portal.html open hoga.
- Portal page par categories, resource downloads, search/filter aur browser tools honge.

SOCIAL LINKS:
Instagram aur YouTube configured hain. Telegram aur WhatsApp buttons abhi placeholder hain, kyunki actual public channel URLs nahi mile. Un links ko jodne ke liye sahi Telegram invite/channel URL aur WhatsApp Channel URL dena.

IMPORTANT:
- Repository delete mat karna.
- ZIP file ko direct upload mat karna.
- Public repository ke files sab dekh sakte hain. Password/private info upload mat karna.
- Ye static website hai; login karke browser se files upload karne wala admin dashboard abhi included nahi hai.
